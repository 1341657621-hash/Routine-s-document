## 知识库分类索引

### 1. 行业动态
- **防晒赛道**：2025年零售额274.5亿元（同比降7.8%）；形态创新（棒/水/粉饼/气垫）；AI赋能（MISTINE线粒体抗光损、资生堂AI香氛喷雾）；婴童防晒"小金盾"成焦点；海龟爸爸2025年GMV 8.2亿，亚洲第一婴童防晒品牌（欧睿认证）
- **青少年护肤**：05后消费规模621亿元（2030年破千亿）；海龟爸爸小蓝瓶SGS检测28天痘痘-54.83%、闭口-67.96%，牵头制定全国首个青少年祛痘团标；椿草/玉泽/悦芙媞/袋鼠妈妈纷纷入局，"以酶抗痘"比刷酸更温和成趋势
- **婴童抗敏感**：海龟爸爸建立亚洲首个少儿皮肤数据库，覆盖全年龄段肌肤痛点，三大核心系列（抗光损、抗敏感、抗油痘）覆盖全周期；安唯伊获CIC"婴童胎脂面霜全网销售额第一"双认证
- **无水美妆**：2025年65.8亿→2028年预计205.63亿元，CAGR约46%，"高认知低渗透"落差达70个百分点
- **情绪美容**：国内首部T/SHRH068-2024标准发布，β-内啡肽/皮质醇成原料巨头布局重点
- **熬夜护肤**：2025年48.70亿元，同比+24.17%，预计2026年53.57亿元

### 2. 竞品动态
- **安热沙（资生堂）**：2026年3月推出「全新蓝宝瓶」儿童防晒，首次布局母婴赛道，主打"非纳米技术"+"小金盾"标志，线上教育+线下体验双向赋能
- **moodytiger**：儿童防晒服订单量增长142%，以"凉感+亲子情感"重新定义防晒，户外场景竞争维度扩大至服饰
- **戴可思**：年度销售额3.74亿领跑天猫婴童护肤，占比7.8%，持续强化"成分党"心智，联合第三方实验室测评
- **润本**：Q1业绩亮眼，防晒啫喱+气垫新品卡位夏季，2025年推出60余款单品，2026年推出防晒保湿日霜、防晒气垫等新品
- **一页**：青少年护肤线持续发力，分龄/分肤质/分场景护理差异化布局
- **珀莱雅**：收购花知晓，加码彩妆品类，完善多品牌矩阵

### 3. 营销案例
- **京东**：听劝式营销（猪猪侠联名+惠英红代言），APP下载量环比+156%；将UGC反馈转化为官方动作，用"听劝"人设拉近品牌与用户距离
- **伊利**："马年找马伊琍"听劝叠加创意，先官宣马思纯推出"马年思念纯牛奶"，继而策划"寻找马伊琍"广告片
- **超能**：官宣肖战为全球品牌代言人，家清赛道"三顶配"组合，覆盖三叶草/三条纹/Y3全产品线
- **红之**：×王源二度合作升级，从卸妆拓展至面部清洁全品类，全周期代言运营（预热→官宣→共创→长线）
- **MISTINE**：第七代AI线粒体抗光损科技，续约王楚钦升级"全球首席防晒代言人"
- **资生堂**：AI配方平台研发香氛喷雾防晒，与MISTINE形成技术竞争

### 4. 艺人代言（近3月）
- **赵露思**：开年6项全球代言，领跑95花
- **单依纯**：40天双奢进阶（香奈儿+蔻驰），香奈儿品牌史上首位00后华人歌手代言人
- **王鹤棣**：阿迪达斯全系代言人（品牌罕见全品类高规格）
- **白鹿**：11个月升任Jimmy Choo全球代言人，大中华区销售额增34%；娜扎水之蔻；杨紫草本初色全球代言人
- **赵丽颖**：7月6日升级为纪梵希全球彩妆及香氛双线代言人（首位华人）——**2026年7月新增**
- **体育明星代言美妆**：孙颖莎×半亩花田、王楚钦×优时颜/MISTINE（全球首席防晒代言人）、樊振东×康如、孙颖莎×妮维雅。运动员"安全性""专业形象""国民影响力"高度契合品牌需求
- **其他重点**：肖战超能全球代言人、李现adidas世界杯开球、王源红之二度合作、王嘉尔韩束、陈昊宇Augustinus Bader、徐梦洁本来BENLAI、丁禹兮蜜丝婷全球防晒代言人、陈立农美康粉黛（7月5日）

### 5. 平台趋势
- **小红书**：Redshop跨境电商平台6月上线；05后消费链路从"搜索先行"→"内容种草→验证→下单"；信任机制从"信达人"→"信真实反馈"；广东315晚会曝光假货产业链（AKF/橘朵/酵色发布打假声明）
- **抖音**：5月化妆品GMV 284.58亿元，赫莲娜登顶TOP1，白牌消失于TOP20；618美容品牌破亿数量同比增长75%
- **天猫**：618化妆品首次纳入政府补贴（12%-20%）；李佳琦直播间54款单品GMV破千万，珀莱雅19条链接居国货第一
- **京东**：618母婴布局+即时零售，5月20日开启预售，6.1儿童节专属优惠
- **Ulta Beauty**：Q1 2026净销售额31.64亿美元（+11.1%），上调盈利预期；**橘朵7月初正式入驻美国Ulta Beauty官网（首批13款单品）**——**2026年7月新增**

### 6. 政策监管
- **国家药监局**：5月通报44批次不合格化妆品，4月通报25批次检出禁用原料；防晒类问题占比47.5%（19批次/40批次）；"小金盾"成婴童防晒硬指标
- **财政部**：2026年育儿补贴999亿元（同比+10.6%），利好母婴基本盘
- **小红书假货**：广东315晚会曝光完整造假链条（高仿生产→回收瓶罐装→伪造保税仓发货），海蓝之谜价差超19倍
- **化妆品合规**：262批次爆雷，防晒品类问题突出，合规品牌需主动公示检测报告

### 7. 资本市场
