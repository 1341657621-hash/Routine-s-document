## 知识库分类索引

### 1. 行业动态
- **防晒赛道**：2025年零售额274.5亿元（同比降7.8%）；2026年Q1主流电商防晒销售额28.47亿元（同比-9.5%），但结构性分化显著：防晒喷雾逆势增长40.6%（销售额1.05亿元），儿童防晒+40.2%领跑，运动服+74.1%、女装+64%为核心增长极；4月防晒电商总盘同比增长19%突破40亿元；100-200元价格带占销售额66%是利润核心；防晒棒在韩国市场份额突破6%，成为"便携补涂"代表剂型；AI赋能防晒（MISTINE线粒体抗光损、资生堂AI香氛喷雾）；婴童防晒"小金盾"成焦点；海龟爸爸2025年GMV 8.2亿，亚洲第一婴童防晒品牌（欧睿认证）；质润推出防晒棒三款（小光盾/小紫盾/小奶盾）分别针对户外/敏感肌/儿童
- **青少年护肤**：05后消费规模621亿元（2030年破千亿）；海龟爸爸小蓝瓶SGS检测28天痘痘-54.83%、闭口-67.96%，牵头制定全国首个青少年祛痘团标；椿草/玉泽/悦芙媞/袋鼠妈妈纷纷入局，"以酶抗痘"比刷酸更温和成趋势；话题声量激增445%
- **婴童抗敏感**：海龟爸爸建立亚洲首个少儿皮肤数据库，覆盖全年龄段肌肤痛点，三大核心系列（抗光损、抗敏感、抗油痘）覆盖全周期；安唯伊获CIC"婴童胎脂面霜全网销售额第一"双认证；戴可思强化"成分党"心智，联合第三方实验室测评
- **无水美妆**：2025年65.8亿→2028年预计205.63亿元，CAGR约46%，"高认知低渗透"落差达70个百分点
- **情绪美容**：国内首部T/SHRH068-2024标准发布，β-内啡肽/皮质醇成原料巨头布局重点
- **熬夜护肤**：2025年48.70亿元，同比+24.17%，预计2026年53.57亿元
- **全球防晒市场**：2024年153.65亿美元→2030年212.28亿美元；中国防晒服市场2026年预计554亿元；婴童防晒CAGR约18%，养肤型防晒CAGR约25%

### 2. 竞品动态 — 防晒赛道（6大快速起量品牌）
- **安热沙（资生堂）**：2026年3月推出「全新蓝宝瓶」儿童防晒，首次布局母婴赛道，主打"非纳米技术"+"小金盾"标志，线上教育+线下体验双向赋能。国际大牌入局儿童防晒，对海龟爸爸形成直接竞争压力
- **MISTINE**：第七代小黄帽搭载AI线粒体级抗光损科技，续约王楚钦升级"全球首席防晒代言人"；AI从营销工具升级为产品研发核心驱动力
- **贝德美**：占据儿童防晒一定份额，专注"96%高天然成分比""快速切断红敏源头"，与海龟爸爸同价格带（100-200元）直接竞争
- **润本**：Q1业绩亮眼，防晒啫喱+气垫新品卡位夏季，2025年推出60余款单品，2026年推出防晒保湿日霜、防晒气垫等新品，精准卡位夏日儿童防晒需求
- **袋鼠妈妈**：宝宝妈妈对抗紫外线，天猫婴童防晒多品牌之一，"无添加""温和不刺激"，在天猫加强实力广告投放

### 3. 竞品动态 — 青少年护肤（5大入局品牌）
- **海龟爸爸**：小蓝瓶SGS检测领跑+全国首个青少年祛痘团标制定者；已抢占"标准制定者"身份，具备定义品类话语权的战略优势；但椿草/玉泽/悦芙媞/袋鼠妈妈纷纷入局，窗口期正在缩小
- **袋鼠妈妈**：全新青少年护理系列，不只是儿童护肤，青少年护理是其传统优势领域。05后消费心智增长时被惠及
- **青青有口、青椰儿童、青萌护肤等新锐品牌**：纷纷进入青少年护肤赛道，"以酶抗痘"比刷酸更温和成技术趋势，窗口期正在缩小
- **青蛇王子**：中国儿童护肤品牌老字号，新品线强化"青少年专用"概念，带着经典品牌的信任优势
- **松达**：以山茶油为核心成分打造婴童洗护产品，在天然成分赛道有差异化优势

### 4. 竞品动态 — 婴童护肤（6大核心竞争品牌）
